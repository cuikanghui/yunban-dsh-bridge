把**希沃云班**班牌上的家长留言，接给本机的 **DeepSeek Harness（DSH）**，再把回答发回云班。

## 它做什么

```
云班班牌留言  ──►  本机桥接器（轮询 + 判重）  ──►  DSH（你的模型 / 人格配置）  ──►  回发到云班
     ▲                                                                              │
     └──────────────────────────── 家长看到的回复 ◄─────────────────────────────────┘
```

- **只处理文字留言**：对方发的文字会被回复；语音、图片、文件会收到一句固定说明
- **带回溯补发**：回答发不出去时进待补发队列，不会因为"后面一条成功了"把这条吞掉
- **不重复回答**：按消息 ID 推进进度，重启后接着上次的位置
- **可暂停**：托盘「启用桥接」取消勾选 = 彻底停用，不轮询、不调模型
- **可自检**：一条命令跑完「登录态 → 云班接口 → 模型问答 → 会话锁 → 回发通道」五段

## 快速开始

### 方式 A：下载安装包（推荐，不需要懂命令行）

1. 打开 [Releases](../../releases) 或本仓库 `dist/` 目录，下载 **`YunbanBridge-Setup.exe`**
2. 双击运行，按提示完成（会创建桌面与开始菜单快捷方式）
3. 双击桌面 **「云班桥接器」** → 托盘出现橙色图标
4. 首次使用会自动弹出浏览器登录窗口，用**家长/老师账号**扫码或输密码登录
5. 登录成功后托盘变绿，开始工作

> 想装到别的盘：先设置环境变量再运行安装包
> ```bat
> set YB_INSTALL_DIR=E:\Tools\YunbanBridge
> YunbanBridge-Setup.exe
> ```

### 方式 B：直接用源码跑（不安装）

1. 下载本仓库（`Code → Download ZIP`）并解压
2. 进入 `src/` 目录
3. 双击 **`云班桥接器.bat`**（默认托盘模式）


## 前置条件

| 项 | 要求 | 缺失时的表现 |
|---|---|---|
| **Windows** | 10 / 11 | — |
| **Node.js** | **22 LTS 或更高**（登录模块用到内置 `WebSocket`） | 托盘提示「未找到 Node.js」，程序不启动 |
| **DeepSeek Harness** | 需已安装（默认装在 `D:\DeepSeekHarness`，也可用 `DSH_APP_DIR` 指定） | 自检第 3 段失败：未找到安装目录 |
| **DSH profile** | 默认使用名为 `yunban` 的 profile（可在配置里改） | 问答失败 |
| **浏览器** | Edge 或 Chrome（登录用） | 登录窗口打不开 |
| **云班账号** | 家长或老师账号（能看到班级留言） | 接口返回 40105 |

## 自检与排错

```bat
:: 安装版
powershell -File "D:\大肥鱼\云班桥接器\tools\selfcheck.js"   :: 只是查看，建议用托盘菜单
node tools\selfcheck.js                                      :: 源码版，在 src/ 下执行
```

自检会依次检查并通过/失败标出：

```
1. 登录态与账号
2. 云班接口 / 班级绑定
3. DSH 启动与问答
4. 会话锁
5. 回发通道
```

**常见问题**

| 现象 | 原因 | 处理 |
|---|---|---|
| `40105 请求未授权` | token 与 `userUid` 不是同一个账号 | 重新登录；或把配置里的 `userUid` 清空让它自动识别 |
| `9999 鉴权失败` | 登录态过期，或被同账号的另一个客户端顶掉 | 重登；同机多客户端请只保留一个或用不同账号 |
| 双击快捷方式没反应 | 托盘已在运行（单实例锁），或 Node 版本过低 | 看托盘区；确认 `node -v` ≥ 22 |
| `启动 DSH 失败：spawn ... ENOENT` | DSH 工作区目录不存在（早期版本的坑，已修） | 更新到最新版；或手动创建 `DSH.workspace` 目录 |
| 托盘图标灰色、不轮询 | 点了「启用桥接」取消勾选 | 重新勾选 |
| 模型总是超时 | 单次回答超过 `timeoutMs` | 调大 `timeoutMs` |

日志位置：`<安装目录>/data/logs/YYYY-MM-DD.log`

## 隐私与安全
